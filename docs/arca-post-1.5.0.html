옴니 넥서스는 RisuAI 대화에 삽화·만화, 목소리(TTS), BGM·효과음, 옴니 뷰어를 붙이는 플러그인입니다. 여섯 기능은 스위치가 따로 있습니다. 삽화만 써도 되고, 목소리만 써도 되고, 음악만 써도 됩니다.
예시 · 삽화 하나만 켠 모습
● 🖼️ 삽화○ 📖 만화○ 🔊 TTS○ 🎵 BGM○ 💥 효과음○ 📽️ 옴니 뷰어
자주 받는 질문
"삽화, TTS, 효과음을 다 써야 하나요?"
아니요. 처음 설치하면 ⚡ 빠른 설정이 열리고, 거기서 고른 것만 켜집니다. TTS·BGM·효과음은 켜기 전까지 꺼져 있고, 안 쓰는 기능의 API 키는 묻지 않습니다. 아래 02에서 내 쓰임새에 맞는 조합을 고르세요.
01 · 스위치

기능은 따로 켜고 끕니다

기능마다 하는 일과 필요한 키가 다릅니다. 키가 필요 없는 기능도 있습니다.

  • 꺼 둔 기능은 키를 묻지 않습니다. ⚡ 빠른 설정의 API 키 단계에는 고른 기능에 필요한 키만 나옵니다.
  • 꺼 둔 기능은 일을 하지 않습니다. TTS와 BGM을 둘 다 꺼 두면 채팅을 지켜보는 일 자체를 하지 않습니다.
  • 나중에 하나씩 더할 수 있습니다. 삽화만 쓰다가 음악을 더하고 싶으면 ⚡ 빠른 설정을 다시 열어 BGM만 누르면 됩니다. 손대지 않은 설정은 그대로 남습니다.
  • OpenRouter 키는 선택입니다. 보조 모델을 직접 고르거나, 임베딩·JEV로 소리와 목소리를 더 정확히 고르고 싶을 때만 씁니다.
02 · 조합

나는 뭘 켜면 될까

내 쓰임새와 가까운 것을 하나 고르세요. ● 표시가 켤 기능이고, 카드 첫 줄 끝은 ⚡ 빠른 설정 첫 화면에서 누를 버튼입니다.

A · 가장 많이 쓰는 조합 · 「그림만」
"그림만 있으면 돼요."
● 삽화○ 만화○ TTS○ BGM○ 효과음○ 뷰어키 1개 · NovelAI
삽화 모듈을 쓰던 분, 폰으로 읽는 분께 맞습니다. 그림 태그를 "메인 모델이 답장 쓰면서"로 두면 모델을 따로 부르지도 않습니다.
B · 그림 없이 · TTS만 누르기
"읽어 주기만 하면 돼요."
○ 삽화○ 만화● TTS○ BGM○ 효과음○ 뷰어키 1개 · Fish Audio
누워서 듣는 분, 그림 요금이 부담인 분께 맞습니다. NovelAI 키가 없어도 됩니다. 캐릭터마다 목소리를 알아서 배정하고, "▶ 누를 때만" 읽게 하면 요금도 듣는 만큼만 듭니다.
C · 키 없이 · BGM·효과음만 누르기
"돈 안 들이고 분위기만 내고 싶어요."
○ 삽화○ 만화○ TTS● BGM● 효과음○ 뷰어키 0개
예제 음악 187곡과 효과음 244개가 들어 있어서 켜기만 하면 됩니다. 장면이 바뀌면 음악이 바뀌고, 문이 닫히면 쾅 소리가 납니다. 둘 중 하나만 켜도 됩니다.
D · 보고 듣기 · 「그림 + 목소리」
"그림도 보고 목소리도 듣고 싶어요."
● 삽화○ 만화● TTS○ BGM○ 효과음○ 뷰어키 2개 · NovelAI + Fish Audio
PC에서 느긋하게 읽는 분께 맞습니다. 음악과 효과음은 키가 필요 없으니, 마음에 들면 나중에 더하세요.
E · 전부 · 「전부 켜기」
"비주얼 노벨처럼 읽고 싶어요."
● 삽화● 만화● TTS● BGM● 효과음● 뷰어키 2개 · NovelAI + Fish Audio
말하는 캐릭터가 표정을 바꾸며 서고, 장소 배경이 깔리고, 줄마다 목소리와 음악이 따라옵니다. 요금과 기다리는 시간이 가장 많이 드는 조합이니, A나 D로 시작해서 익숙해진 뒤에 켜는 것을 권합니다.
F · 다른 모듈과 함께
"삽화(또는 TTS)는 이미 쓰는 모듈이 있어요."
같은 일을 하는 기능은 한쪽만 켜 두세요. 삽화 모듈을 계속 쓴다면 옴니에서는 TTS나 BGM·효과음만, TTS 모듈을 계속 쓴다면 옴니에서는 삽화만 켜면 됩니다.
G · 아끼면서
"요금이나 배터리가 걱정돼요."
삽화는 한 답장에 1장으로, 자동 생성 대신 원하는 메시지에서만 버튼으로 만드세요. TTS는 "▶ 누를 때만"으로 둡니다. 1.4.13부터 첫 실행 뒤로는 시작할 때 채팅을 읽지 않고, 그림 한 장에 드는 읽기도 크게 줄었습니다.
03 · 설정

⚡ 빠른 설정으로 1분 만에

처음 설치하면 설정 창과 함께 열립니다. 다시 열 때는 설정 창 🔍 왼쪽의 ⚡ 빠른 설정입니다. 1.5에서 새로 만들어, 창 크기가 바뀌지 않고 여섯 단계가 늘 보입니다.

1무엇을 쓸까요
쓸 기능만 누릅니다. 「그림만」「그림 + 목소리」「전부 켜기」「모두 끄기」로 한 번에 고를 수도 있습니다. BGM과 효과음은 따로 켭니다.
2그림
한 답장에 1장 / 1~2장 / 2~3장 / 3~4장, 만화 비율(가끔 / 반반 / 자주 / 전부), 그림 태그를 누가 쓸지. 그림을 안 고르면 건너뜁니다.
3소리
TTS를 언제 읽을지(새 답장이 오면 바로 / ▶ 누를 때만), 나레이션도 읽을지, 효과음을 어떻게 고를지. 소리를 안 고르면 건너뜁니다.
4모델
보조 모델은 Risu에 설정한 것을 그대로 쓰면 됩니다. 따로 고르고 싶을 때만 바꿉니다.
5API 키
앞에서 고른 기능에 필요한 키만 나옵니다. 키마다 무엇에 쓰는지, 어디서 받는지 적혀 있고, 「확인」을 누르면 키가 맞는지 바로 알려 줍니다.
6확인
지금 설정과 달라지는 항목에 「변경」이 붙습니다. 적용하면 고른 것만 바뀝니다.

1.5 업데이트 내역

1.4.4 ~ 1.4.16

⚡ 빠른 설정을 새로 만들었습니다

  • 창 크기가 처음부터 끝까지 같습니다. 고를 때마다 창이 출렁이지 않습니다. 휴대폰에서는 화면 전체를 씁니다.
  • 왼쪽(휴대폰은 위)에 여섯 단계가 늘 보이고, 눌러서 바로 이동합니다. 물어볼 게 없는 단계는 건너뜁니다.
  • BGM과 효과음을 따로 켜고, 이미지 수와 만화 비율을 더 잘게 고릅니다.
  • API 키는 필요한 것만 묻고, 👁로 보고, 「확인」으로 바로 검사합니다. 붙여 넣을 때 섞인 공백은 지웁니다.
  • 열었다가 손대지 않고 적용하면 세부 값은 그대로 둡니다.

🎵 BGM이 같은 곡만 돌지 않습니다

  • 전에는 같은 분위기면 늘 목록 앞쪽 세 곡만 나왔습니다. 이제 태그가 겹치는 곡이 모두 후보입니다.
  • 임베딩을 쓰면 음악 큐 바로 뒤의 장면을 곡마다 적힌 「상황」과 비교해 고릅니다. 임베딩이 없어도 후보 중에서 고루 뽑습니다.
  • 예제 187곡에 어떤 장면에 어울리는지 「상황」을 적었습니다. BGM 수정 창에서 고칠 수 있습니다.

💥 효과음과 🔊 목소리를 더 잘 고릅니다

  • 효과음 「임베딩만」은 소리 단어와 앞뒤 문단을 함께 봅니다. 같은 "쾅"이라도 문인지 총인지 천둥인지를 장면으로 가립니다.
  • 예제 효과음이 18개 늘었고, 효과음마다 들리는 소리와 상황이 적혀 있습니다.
  • 같은 봇의 캐릭터끼리 목소리가 겹치지 않습니다. 음성 태그를 더 잘게 나눴고(나이 여섯 단계, 음높이, 음색), 첫 대사 이모지를 더 많이 알아봅니다.

🔋 빨라지고 배터리를 덜 씁니다

  • 시작할 때 모든 채팅을 두 번씩 읽던 것을 없앴습니다.
  • 그림 한 장을 만들 때 봇 전체를 읽는 횟수를 26번에서 3번으로 줄였습니다.
  • TTS와 BGM을 둘 다 꺼 두면 채팅을 지켜보지 않습니다.

🖼️ 그림과 캐릭터

  • New POV: 시점 인물도 캐릭터로 다룹니다.
  • ComfyUI에서 캐릭터 위치, 마스크, 참고 이미지를 씁니다.
  • 등록한 코스튬 태그가 그림을 만들다가 사라지지 않습니다.
  • 전역 캐릭터를 여러 명씩 현재 챗으로 옮길 수 있고, 현재 페르소나에 맞는 전역 캐릭터만 쓰게 할 수 있습니다.
  • 감정 에셋과 배경을 세션·캐릭터 프리셋으로 보관합니다.

📽️ 옴니 뷰어

  • 배속, 요소 접기, 다음 메시지로 넘기기가 생겼습니다.
  • 작동 창에서 뷰어 높이를 조절하고 닫기 바로 닫습니다.
  • 삽화 목록이 10장을 넘어도 다 보입니다.
