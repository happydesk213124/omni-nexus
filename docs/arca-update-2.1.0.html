큐레이터 사용법
설정 탭의 큐레이팅에서 모드를 고릅니다.
사용 안 함 — 지금과 같이 자유 태그 생성.
2단 — LLM이 카탈로그 그룹·옵션을 고른 뒤, 그 ID로 장면/액션 태그를 조립합니다. 캐릭터 외형·복장 태그는 카탈로그가 덮어쓰지 않습니다.
임베딩식 — 자유 태그를 카탈로그와 비슷한 항목으로 스냅합니다. (임베딩 API·사전 임베딩 필요)
기본 카탈로그는 소형 SFW입니다. NovelAI식 그룹 JSON을 카탈로그 업로드로 넣을 수 있습니다.
엄격 ID 모드(2단일 때만): 카메라·상황·자연어·액션/표정을 자유 문장으로 쓰지 않고 카탈로그 ID만으로 조립합니다.
왜 쓰면 좋은가 / 단점
장점
· 장면·포즈·소품 표현을 카탈로그 어휘로 맞추기 쉬움
· 캐릭터 외형/복장은 로스터 쪽을 유지한 채 상황만 정리
· 엄격 ID면 환각성 자유 태그 대신 등록된 옵션만 사용
단점
· LLM 호출이 한 번 더 들어가 비용·지연이 늘 수 있음
· 엄격 모드·임베딩식은 카탈로그 업로드(및 임베딩 설정)가 사실상 필요
· 마법이 아님 — 카탈로그에 없는 연출은 고를 수 없고, 품질은 카탈로그·프롬프트에 좌우됨
업데이트 사안
· 큐레이팅 탭: 모드 / 엄격 ID / 카탈로그 업로드·리셋 / 임베딩 생성·테스트
· 스티키 항상이미지: NAI 가로·세로 비율에 맞게 프레임을 줄이고, 잘리지 않게(contain) 표시. 레터박스 배경은 투명
· NAI 해상도: 예전 832×1216 상한·픽셀 상한을 완화 (사용자 설정 크기를 더 그대로 사용, 비정상 값만 1~5000 클램프)
· 인원 태그 강조: 카드 설정의 사람 태그 가중치(0~5, 기본 3)로 N::1girl, 1boy:: 형태 적용
· 프롬프트 탭: 기본값 일괄 복원(작성자 노트 제외), 전체/개별 JSON 내보내기·가져오기
· 장신구·무기 힌트 분리 등 태그/로스터 쪽 정리
향후 개발 방향
· 캐릭터 에셋을 자동으로 찾아, 캐릭터 프롬프트를 미리 채워 두기
· 이미지 메시지 삽입 기능 추가 예정 (삽화 모듈처럼)
