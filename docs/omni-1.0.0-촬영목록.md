# 옴니 넥서스 1.0.0 소개글 촬영 목록

본문: `아카라이브_옴니넥서스_가이드.html`

HTML에는 사진·영상 대신 촬영 지시를 글로 넣었다. 업로드한 사진이나 영상을 해당 문구 자리에 넣고 촬영 지시 문구는 지우면 된다. 모든 화면은 같은 캐릭터와 스타일로 찍으면 흐름을 따라가기 쉽다.

## 우선 촬영

| 번호 | 종류 | 찍을 내용 |
|---|---|---|
| 영상 01 | 20~30초 | 소개글 맨 위 대표 영상. 생성 시작 → 이미지 순차 표시 → 크게보기 → 샷 태그 수정. |
| 영상 02 | 15~30초 | 답변이 스트리밍되는 동안 생성 진행 안내가 뜨고 결과가 보이는 과정. 표식 뒤에 부가 내용이 있는 대화 사용. |
| 영상 03 | 20~40초 | 샷 태그 수정에서 시드 고정 → 표정 또는 의상 한 항목 변경 → 생성 → 히스토리에서 전후 비교. |
| 스크린샷 01 | 1장 | 캐릭터 탭에서 외형과 여러 코스튬이 보이도록 촬영. |
| 스크린샷 02 | 1장 | 세션 작가의 노트에서 장소·캐릭터별 코스튬·옷 상태가 보이도록 촬영. |
| 스크린샷 04 | 2장 | 같은 캐릭터의 일반 삽화와 만화 결과. 각각 원본 업로드도 가능. |

## 사용법 보충

| 번호 | 종류 | 찍을 내용 |
|---|---|---|
| 스크린샷 03 | 2장 | 대시보드의 설정 프리셋, 스타일 프리셋 탭. 이름과 복제·저장·적용 버튼이 보이게. |
| 스크린샷 05 | 1장 | 만화 생성 설정. 비율·최대 페이지·가로/세로/정사각 선택 부분. |
| 스크린샷 06 | 2장 | 메인 태깅 모델 연결 화면, 이미지 모델 연결 화면. API 키·개인 주소 가리기. |
| 영상 04 | 15~25초 | 플로팅 뷰어 접기·펼치기 → 크게보기 → 탐색기 폴더와 여러 장 선택. |
| 영상 05 | 10~20초 | 메시지의 ⚛️ 버튼 → 진행 안내 → 채팅에 남은 이미지. 초보자용 첫 생성. |

대표 영상 01과 첫 생성 영상 05는 같은 촬영본에서 필요한 구간을 잘라 써도 된다. 편집 전후는 시드가 같아도 구도가 바뀔 수 있으므로 실제 결과를 그대로 사용한다.

## 게시 전 마무리

- 1.0.0의 `dist/omninexus.js` 파일 또는 실제 배포 링크를 본문 두 다운로드 자리에 추가.
- 스크린샷·영상을 올리고 각 촬영 지시 문구를 삭제.
- 아카라이브 HTML 편집기에 HTML 본문을 붙여 넣고 저장한 뒤 새로고침하여 PC·모바일, 밝은·어두운 테마, 접기 항목을 확인.
- 현재 HTML은 제공된 v6.5 가이드의 허용 태그와 인라인 스타일로 작성했다. 실제 아카라이브 저장·재로드는 별도로 확인해야 한다.

## 작성 기준

- 비교 대상은 제공된 `test레퍼.txt`의 라이트보드 삽화 4.5.1. 해당 모듈 외부에 있는 Lightboard 공통 라이브러리 전체까지 비교한 것은 아니다.
- 비교 대상에도 있는 만화·프롬프트 편집·재생성·캐릭터 태그 기록·ComfyUI 연계를 옴니 전용 기능으로 소개하지 않았다.
- 예전 인레이 가이드의 큐레이팅 설치 안내, Proton 링크, 50% 스트리밍 조건과 구식 Base 버튼 설명은 현재 사용법으로 옮기지 않았다.
- 코드 확인: 스트리밍 도움말은 `docs/settings-ux-preview.html`, 캐릭터·갤러리는 `src/services/`, 편집 기능은 `src/tag-studio/mount.ts`, 설정 프리셋은 `src/services/settings-presets.ts`와 `src/settings-ux/settings-presets.ts`.
- TTS와 FISHTTS는 개발 중으로 안내한다.
