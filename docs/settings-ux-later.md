# 설정창 이후 할 일

초안은 `docs/settings-ux-preview.html`. **설정 UX 포트에서 반영된 것:**

- 왼쪽 줄 오버레이는 저장값을 꺼 두고 그리지 않음. 떠 있는 그림은 플로팅 뷰어만.
- TTS 탭(큐레이팅 자리): 켜기·목소리·속도·시험 듣기. 박제 후 그 줄 읽기. 옛 큐레이팅 칸은 hidden.
- 참고컷 생성 1024×1024.
- 캐릭터 상의=`attire` / 하의=`bottoms` / 무기=`accessories`. 옛 세이브의 하의는 빈 칸(쪼개 추정 안 함).
- 설정 헤더(탭 이름·바로 저장됨·?·EXPORT·IMPORT·닫기). 왼쪽 날. 설정 저장 버튼은 숨김.
- 프리셋/캐릭터 타일 그리드 + 80% 수정 시트. 캐릭터·탐색 오른쪽 패널.
- 디버그 첫 화면은 할당량. 만화 작가/선행/후행 칸은 높게.

한 줄로: 옴니는 **말이 끝나면 그 줄에 그림을 박제**하고, 따라가기 핀은 쓰지 않는다.
