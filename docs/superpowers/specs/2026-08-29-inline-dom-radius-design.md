# 인라인 DOM 탐색 반경 설정

## 목표

대시보드에서 인라인 이미지·스피너가 탐색할 말풍선 반경을 조절한다.
기본값은 현재 동작과 같은 4이며, 저장 가능한 범위는 3~20이다.

## 설계

- `card.inline_chat_dom_radius`에 정수 설정을 저장한다.
- 기존 설정에 값이 없거나 잘못된 값이면 4를 사용하고, 유효 값은 3~20으로 제한한다.
- 대시보드에 `스피너 DOM 탐색 숫자` 숫자 입력을 추가한다.
- 역할 prefetch와 실제 keep 탐색이 같은 설정값을 사용한다.
- 숫자 N은 선택 기준 양쪽에서 적격 말풍선을 최대 N개씩 뜻한다.
- 기존 유저 역할 및 짧은 메시지 제외 규칙은 변경하지 않는다.

## 검증

- 기본값·마이그레이션·최솟값·최댓값을 단위 테스트로 고정한다.
- 대시보드 입력 저장과 런타임 반경 전달을 빌드 레이아웃 테스트로 확인한다.
- 전체 테스트, parity, production build를 실행하고 생성된 `dist/inlaynexus2.0.js`를 커밋한다.
