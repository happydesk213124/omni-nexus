Omni Nexus 1.2 · TTS

설정의 TTS 탭에서 사용합니다. 삽화 대시보드 전원과 별개로 켜고 끌 수 있습니다. 이전 검수 HTML은 실제 플러그인과 연결되지 않는 시안입니다.

처음 설정

  1. TTS 사용을 켜고, 모델 설정에 Fish API 키·URL·모델명을 입력합니다.
  2. 음성 목록에서 음성을 하나 선택해 나레이션으로 지정합니다. 캐릭터는 직접 만들거나 LLM으로 자료를 읽어 추가합니다. 자동 배정에 사용할 보조 LLM도 지정합니다.
  3. 음성 재생 활성화를 한 번 누릅니다. 브라우저 세션이나 정책에 따라 다시 눌러야 할 수 있습니다.
  4. OmniTTS 모듈은 자동 설치됩니다. Risu가 데이터 접근 권한을 요청하면 허용해야 모듈을 저장할 수 있습니다. 새 대사에 표시되는 ▶ 버튼으로 듣습니다.

모듈은 하린 (happy): "안녕하세요." 형식의 이름·영어 억양을 요청하고, 표시용 div와 버튼만 만듭니다. 통신·캐시·음성 재생은 플러그인이 담당합니다. 원문 메시지는 고치지 않습니다.

재생과 캐시

화면 중앙에 가까운 구간부터 앞뒤 양쪽을 최대 50개 준비합니다. 스크롤하면 대기 중인 준비 범위를 바꿉니다. 이미 실행 중인 요청은 완료해 캐시에 남깁니다. 모든 Fish 생성은 최대 5개 자리를 공유하며, 클릭한 요청은 다음 빈 자리에 먼저 들어갑니다.

동일한 음성·모델·억양·변환된 대사는 메시지가 달라도 재사용합니다. 배속·볼륨은 재생할 때 적용하므로 재생성을 일으키지 않습니다. 캐시는 기기 저장소에 압축 MP3로 저장하고 용량 한도를 넘으면 오래 사용하지 않은 항목부터 지웁니다.

재생기는 하나입니다. 새 클릭·정지·전원 OFF 후 이전 응답이 도착해도 다시 재생하지 않습니다. 플로팅 뷰어의 ↪을 끄면 한 구간만 듣습니다. 나레이션·이어 읽기·배속·볼륨·패널·최소화 상태는 저장됩니다.

캐릭터와 음성 목록

캐릭터는 현재 채팅 또는 글로벌 범위로 저장합니다. 동명이면서 확인된 성이 다르면 합치지 않습니다. 공통 별명만으로 두 사람 중 하나를 추측하지 않습니다. 고정 음성은 자동 추천으로 덮어쓰지 않습니다.

음성 타일은 선택 후 다시 열어 수정합니다. 다중선택 모드·Shift 범위 선택·폴더 이동·삭제 확인을 제공합니다. 검색에서 여성 & 차분 | 남성 & 중년처럼 AND와 OR를 쓸 수 있습니다. 폴더 JSON은 새 폴더 이름을 정해 가져옵니다. 듣기는 한국어·일본어·영어 인사 한 문장을 바로 요청합니다.

LLM 가져오기·정리는 번호 JSON을 검증한 뒤 선택한 결과만 적용합니다. JEV도 후보 번호를 사용하고 첫 번째 추천을 기본 선택합니다. JEV 후보는 성별별 최대 255개이므로 많은 목록은 폴더로 좁혀 주세요.

번역과 삽화 읽기

번역은 듣는 텍스트에만 적용합니다. LLM은 여러 구간을 묶고, Google 무료 번역·Google Cloud·DeepL도 선택할 수 있습니다. 무료 Google 경로는 공식 Cloud API가 아니어서 서비스 변경에 영향을 받을 수 있습니다.

삽화 아래 ▶은 저장된 캐릭터 이름과 korean text 메타데이터가 있는 삽화를 읽습니다. 누르면 우측에 캐릭터 칩이 생깁니다. 일반 메시지 연속 재생 목록에는 삽화 대사를 추가하지 않습니다. 메타데이터가 없는 예전 이미지에는 읽을 대사가 없다는 안내가 나옵니다.

외부 정규식과 저장 위치

첨부된 정규식 export의 활성 표시 규칙과 함께 검사했습니다. 외부 표시 변환 뒤에 Omni 삽화·메시지 도구·TTS HTML을 만드는 순서를 사용해 버튼이 숨겨지는 충돌을 피합니다. Lua는 줄 단위로 읽고, Omni 정규식의 토큰 길이와 경계를 제한했습니다. 임의의 다른 정규식 자체에 있는 성능 문제까지 제거하는 방식은 아닙니다.

TTS 설정·음성·캐릭터는 별도 omnitts.data에 저장합니다. 기존 삽화 캐릭터·설정 키를 덮어쓰지 않습니다. 음성 캐시와 번역 캐시는 기기 저장소의 omnitts.cache.*, omnitts.translations를 사용합니다.

검증 범위

소스 검사, 실제 Lua 실행, 첨부 정규식 조합, 브라우저 설정 UI, 제한된 Risu SafeDOM 모의 환경에서 검사합니다. 실제 설치된 Risu 및 유료 Fish·번역·LLM·JEV 계정 호출은 별도 실기 확인이 필요합니다. 검수 채팅 버튼과 시뮬레이션은 제품에 포함하지 않습니다.
