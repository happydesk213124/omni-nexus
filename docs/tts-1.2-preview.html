ComfyUI 사용법

처음 설정하기

  1. ComfyUI에서 사용할 모델·커스텀 노드를 준비하고, 먼저 워크플로가 그림을 정상 생성하는지 확인합니다. 결과를 받으려면 SaveImage 같은 이미지 출력 노드가 연결되어 있어야 합니다.
  2. ComfyUI 설정 → Comfy → Dev Mode에서 Enable dev mode options (API save, etc.)를 켭니다. API 내보내기 메뉴가 이미 보이면 바로 다음 단계로 넘어가도 됩니다.
  3. File 또는 Workflow → Export (API)로 JSON을 받습니다. 구버전에서는 Save (API Format)으로 표시될 수 있습니다. 일반 저장 JSON은 사용할 수 없습니다.
  4. 내보낸 JSON을 이 입력란에 붙여넣거나 JSON 파일 불러오기로 불러옵니다. 각 노드의 inputs 안에서 바꾸고 싶은 값에 아래 마커를 넣습니다. 숫자 칸은 내보낸 JSON에서 직접 수정하세요.
  5. ComfyUI URL에 실행 중인 서버 주소를 넣습니다. 같은 기기라면 보통 http://localhost:8188입니다. 다른 기기에서 Risu를 쓰면 ComfyUI 기기의 주소와 외부 접속 설정이 필요합니다.
  6. 설정이 저장된 뒤 지금 생성으로 확인합니다. 현재 ComfyUI의 연결 테스트 버튼은 설정을 저장하고 실제 연결 검사는 생략합니다. 성공 표시만으로 생성 가능 여부를 확인할 수는 없습니다.

프롬프트 · 캐릭터

긍정 프롬프트를 받는 텍스트 입력에는 [[pos]], 부정에는 [[neg]]를 넣습니다. [[pos]]는 필수이며, 호환 표기 {{risu_prompt}} / {{risu_neg}}도 지원합니다.

캐릭터 태그를 따로 넣으려면 [[char1]]부터 [[char6]]까지 사용합니다. 번호는 이번 샷의 캐릭터 순서이며, 해당 캐릭터가 없으면 빈 문자열입니다. [[neg]]에는 캐릭터의 부정 태그도 합쳐집니다.

"text": "[[pos]], [[char1]], [[char2]]"

스타일 프리셋에서 @ch1@ 같은 캐릭터 마커를 이미 쓰면 그 캐릭터 태그는 [[pos]]에 합쳐지고 해당 [[char1]]은 비워집니다. 캐릭터를 별도 입력에 넣으려면 프리셋의 해당 @chN@을 빼세요. 마커를 넣는 것은 텍스트 전달이며, 캐릭터 영역·위치를 나누려면 워크플로에도 그에 맞는 노드가 필요합니다.

크기 · Steps · CFG

EmptyLatentImage 등 실제 크기를 받는 노드에 아래처럼 따옴표로 감싸서 넣습니다. 값 전체가 마커이면 전송할 때 숫자가 됩니다. [[steps]]와 [[cfg]]는 Omni의 생성 Steps·CFG 값을 전달합니다.

"width": "[[width]]",
"height": "[[height]]",
"steps": "[[steps]]",
"cfg": "[[cfg]]"

자동 비율 조절이 켜져 있으면 샷에 맞춰 세로 832×1216, 정사각 1024×1024, 가로 1216×832를 사용하고, 꺼져 있으면 Models의 NAI Width/Height를 사용합니다. 생성 크기를 별도로 지정한 작업은 그 크기를 우선합니다. 마커가 없는 숫자 칸은 워크플로에 적힌 값을 유지합니다. 모델·샘플러·스케줄러는 워크플로에서 직접 설정하세요.

시드

"seed": "[[seed]]"로 쓸 수 있습니다. 마커 없이 숫자로 적힌 seed와 noise_seed도 Omni가 이번 생성의 시드로 덮어씁니다. 생성 작업이나 NAI Seed에 양수가 지정되어 있으면 그 고정값을 쓰며, 없거나 0이면 매번 랜덤입니다. 워크플로의 숫자만 바꿔서는 시드를 고정할 수 없습니다.

참조 이미지

Models의 NovelAI 쪽 참조 이미지에 그림을 올린 뒤 ComfyUI로 돌아와, LoadImage 노드에 "image": "[[ref]]"를 넣습니다. Omni가 그 그림을 ComfyUI에 업로드하고 파일 이름을 채웁니다. 캐릭터별 참고이미지와는 별개입니다.

참조가 없으면 [[ref]]는 빈 문자열이 됩니다. LoadImage 노드가 자동으로 삭제되지는 않습니다. 이미지가 꼭 필요한 워크플로라면 참조를 올리거나, ComfyUI에서 참조 없는 흐름을 따로 준비하세요.

조건부 마커

텍스트 입력 안에서 [[#char1]]…[[/char1]]로 감싸면 캐릭터 값이 있을 때만 그 안의 내용이 남습니다. 없으면 헤더까지 함께 지워집니다. char2~char6, ref에도 같은 형식을 쓸 수 있습니다.

"text": "[[pos]]\n[[#char1]]\n## Character 1\n### Outfit, Appearance Design & Facial Expression\n[[char1]]\n[[/char1]]"

조건부 마커는 inputs의 문자열 안에서만 작동합니다. JSON의 노드나 연결을 감싸서 제거하는 기능은 아닙니다. JSON 문자열 안 줄바꿈은 예시처럼 \n으로 적으세요.

강조 · 문제가 생겼을 때

Omni가 만든 2::hard:: / {{happy}}는 ComfyUI로 보낼 때 (hard:2) / ((happy))로 바뀝니다. 양수 강조는 긍정에 남고, 음수 강조는 부정 프롬프트로 옮깁니다.

  • JSON 오류: 일반 저장 파일 대신 API 형식인지, 쉼표·따옴표가 맞는지 확인하세요. API 형식은 노드 ID 아래에 class_type과 inputs가 있는 객체입니다.
  • 태그·크기가 적용되지 않음: 마커가 실제 생성에 연결된 노드의 inputs 값에 들어 있는지 확인하세요. 알 수 없는 이름의 마커는 그대로 남습니다.
  • 제출 실패: ComfyUI에서 빠진 모델·커스텀 노드·입력 이미지를 확인하세요.
  • 완료됐지만 출력 이미지 없음: SaveImage 등 이미지 출력 노드를 확인하세요. 여러 출력이 있으면 Omni는 출력 목록에서 처음 찾은 이미지 한 장을 받습니다.
  • 시간 초과: 기본 대기는 300초입니다. 큰 모델이나 긴 대기열이면 Timeout을 늘리세요(30~1800초). Omni의 대기가 끝나도 ComfyUI 작업이 자동 취소되지는 않습니다.
